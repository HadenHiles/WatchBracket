# Roadmap

Watch Bracket V1 covers the complete self-hosted room, nomination, Double-Take tournament, media integration, winner, replay, presentation, and deployment lifecycle.

Potential post-V1 work is intentionally optional:

- passkeys or TOTP for administration;
- additional media-server adapters through the typed provider boundary;
- reliable profile-private next-episode resolution;
- host-configurable no-repeat and dealbreaker variants;
- translated controller and display copy;
- packaged multi-architecture images and signed release provenance;
- optional metrics/export integrations that remain off by default;
- horizontal game API scaling if real installations demonstrate the need.

The project does not plan to require Redis, an LLM, a cloud control plane, public guest accounts, or a plugin marketplace for core movie-night use.
