# Code of Conduct

Watch Bracket is a welcoming project for media-server enthusiasts of every background and experience level.

Be respectful, constructive, and patient. Assume good intent while addressing the actual impact of words and actions. Harassment, discrimination, threats, sexualized attention, doxxing, and sustained disruption are not accepted in project spaces.

Maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior harms the community. Enforcement decisions should be proportionate, documented privately, and protect the safety and privacy of reporters.

Report conduct concerns privately through the repository owner's GitHub profile or a private GitHub Security Advisory when the concern also involves security or sensitive information. Do not disclose another person's report publicly without permission.
